# End-to-End Student Performance Prediction using Random Forest Regression

## 📌 Overview
This project focuses on predicting student exam scores using machine learning techniques. It demonstrates a complete data science workflow from data preprocessing to model evaluation.

## 📊 Dataset
The dataset contains student-related features such as:
- Hours studied
- Sleep hours
- Attendance percentage
- Previous scores

## ⚙️ Approach
1. Data Loading and Exploration
2. Feature Selection
3. Train-Test Split
4. Model Building using Random Forest Regressor
5. Model Evaluation using Mean Absolute Error (MAE)
6. Visualization of Actual vs Predicted scores

## 🤖 Model
- Algorithm: Random Forest Regressor
- Evaluation Metric: Mean Absolute Error (MAE)

## 📈 Results
- Achieved MAE ≈ 3.18
- Model predictions closely align with actual exam scores

## 📊 Visualization
- Scatter plot comparing actual vs predicted values
- Feature importance analysis

## 🧠 Key Insights
- Study hours and previous scores strongly influence performance
- Attendance also contributes significantly
- Model demonstrates strong predictive capability

## 🚀 Conclusion
This project showcases an end-to-end machine learning pipeline for regression tasks and highlights the importance of data-driven decision making.

## 🔗 Tech Stack
- Python
- Pandas
- Scikit-learn
- Matplotlib
